# Public-evidence baseline

The selected development route is hybrid public evidence plus isolated local downstream design tool integration. `source-manifest.json` freezes primary benchmark methodology documents by repository commit and SHA256. These documents explain how to obtain and retain evidence; they are not GPU throughput profiles and cannot activate as qualified performance packs.

Next evidence ingestion should target exact model/runtime/GPU configurations required by customer cases. Preserve the benchmark release, execution fingerprint, workload distribution, latency and quality conditions, source artifacts and applicable reuse rights. A headline throughput number alone is not sufficient. Private datasets and targeted measurement campaigns are intentionally deferred nearer release.

The source-capture script is an explicit curator/developer operation requiring internet access. Ordinary compilation never resolves a remote URL or floating repository branch.
