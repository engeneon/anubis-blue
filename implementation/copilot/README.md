# Historical Copilot implementation evidence

These records document the consultant pilot and usability corrections made during the November 2026 implementation. They are retained as historical engineering evidence, not as a statement that all current workloads or model providers are qualified.

- `consultant-pilot.txt` is the three-case human pilot linked from the project README. Its specialist case deliberately exercises incomplete-input handling.
- `random-scenario.json` preserves the original random scenario selection used by the earlier implementation workflow.
- The dated correction notes explain navigation, advanced editing, progress feedback, engagement completion and closure without a handoff.
- `validation.json` records its original software-check commands and SHA-256 digests. The accompanying logs match those recorded digests.

For current GPU-complete demonstrations use `docs/gpu-complete-scenarios.md` and `docs/playbooks`. For the saved-result explanation release use `testing-evidence/explanations/README.md`. Earlier pilot scope and test counts must not replace those newer release records.

Provider credentials, local databases, intermediate model sessions and failed screenshot captures are not included here.
