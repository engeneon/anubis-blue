# MVP workflow evidence

This evidence records the fictional Case A document-assistant workflow referenced by the project README. It includes a fixed source-linked proposal, manual and assisted calculation outputs, screenshots, handoff and completion records, and the original validation summaries.

The assisted proposal was supplied through the API. This evidence does not claim live LLM interpretation qualification. Expected workload sizing is eight GPUs, with a separate 256-GPU factory deployment anchor. The external document corpus is not silently treated as local storage or an initial transfer requirement.

These are saved observations, not tests rerun by adding this archive to Git. Current scenario and explanation release evidence is under `testing-evidence/gpu-readiness` and `testing-evidence/explanations`.
